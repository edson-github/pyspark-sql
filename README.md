# PySpark SQL Training Environment

This repository contains resources and examples for learning PySpark SQL operations and transformations. It provides a structured environment for practicing SQL-like operations in a distributed computing context using Apache Spark's DataFrame API.

## Prerequisites

- Python 3.x
- Java 8 or later (required for PySpark)
- Apache Spark
- PySpark

## Environment Setup

1. Install Python dependencies:
```bash
pip3 install pyspark
```
